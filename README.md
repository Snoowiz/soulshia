# Soulshia

Soulshia is a robust social media platform built using Laravel and Vue.js 3.

### Key Features

- **Modern Technology Stack**: Powered by Laravel 11 and Vue.js 3, ensuring a powerful and scalable foundation.
- **Real-time WebSockets & Queues**: Integrated with Laravel Reverb WebSockets and Redis Horizon for instantaneous messaging and background processing.
- **Docker Support**: Preconfigured Docker Compose environment for seamless local development and production VPS deployments.
- **Long-term Support**: Ongoing updates and active development.
